# Vellore Catering World — White Editorial Redesign V15

This redesign keeps the existing site content and media but changes the visual system across the full static site.

## Design direction
- White site background throughout.
- Forest green typography and controls with warm saffron/copper accents.
- Full-width clean white navigation instead of the previous dark glass/floating nav.
- Homepage and inner heroes changed from full-image dark overlays to light editorial split layouts with large rounded image cards.
- Rounded pill buttons, soft shadows and large white cards replace dark/gold bordered panels.
- Catalog, service, area, blog, menu, gallery, FAQ, form and footer components all use the new light system.
- Existing local images, videos, content, SEO metadata, links, forms and scripts remain in place.
- Responsive mobile navigation and responsive hero imagery are retained.

## Source of truth
`assets/css/main.css` now includes the V15 override block at the end. The original V14 stylesheet was retained as `assets/css/main.pre-white-redesign.css` for reference.

## Cache version
Public HTML references `main.css?v=15`.
