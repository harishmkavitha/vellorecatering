VELLORE CATERING WORLD — GITHUB UPDATE
======================================

This package is the merged website containing media work for Batches 01–27.

To replace the current GitHub project:
1. Extract this ZIP.
2. Open the vellorecatering-main folder.
3. Copy/replace the contents into your existing GitHub repository working folder.
4. Run:

   git add .
   git commit -m "Integrate catering media batches 01 to 27"
   git push origin main

Batches 01–11 include the local videos created earlier.
Batches 12–27 intentionally use CSS image motion instead of video.
